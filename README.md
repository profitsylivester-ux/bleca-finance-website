# BLECA SmartLabs — Finance & Accounting Website

The official website for the **Finance & Accounting Department** of BLECA SmartLabs.

This is a multi-page static website that presents the department to visitors, partners, funders, and staff. It includes an AI-style assistant that answers common questions about the department.

## About the Department

The Finance & Accounting Department ensures that every shilling BLECA spends is tracked, approved, documented, and reported. The team manages:

- Cash and bank accounts
- Budgets and planning
- Invoicing and payments
- Financial records and documents
- Reporting
- Compliance and audit support

**Tagline:** *Finance that serves the mission.*

---

## Features

- Five public pages: Home, About, Services, Team, Contact
- Shared navbar and footer across all pages
- Mobile-first responsive design with a hamburger menu
- Floating chatbot assistant (bottom-right) with:
  - Typo correction
  - Suggested questions
  - Quick reply buttons
  - Typing indicator
  - Safe answers to common questions
  - Sensitive-topic protection (never shares real financial data)
- Contact form that opens the user's email client
- Staff portal placeholder page
- Social links: Instagram, LinkedIn
- Accessibility: ARIA labels, keyboard navigation, focus outlines
- SEO-friendly titles and meta tags

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom styles, Flexbox, Grid, media queries
- **JavaScript (Vanilla)** — hamburger menu, contact form, chatbot
- **No frameworks. No build step. No dependencies.**

The site is intentionally simple: it loads fast, works everywhere, and can be hosted anywhere.
